---
title: Configuration
description: Every environment variable the app reads.
---

Variables starting with `NUXT_` are read at runtime, so changing them needs a restart but no rebuild. The others set
defaults when `bun run build` runs. `.env.example` lists the same set.

## Required in production

| Variable | Description |
| --- | --- |
| `NUXT_APP_SECRET` | Nuxt's root secret; the session cookie is sealed with a key derived from it. At least 32 characters. Generated automatically in development. |

## Database

| Variable | Default | Description |
| --- | --- | --- |
| `LIBSQL_URL` | `file:./.data/events.db` | libSQL connection URL: a file, `http(s)://` for sqld, or `libsql://` for Turso. |
| `LIBSQL_AUTH_TOKEN` | — | Token for Turso or a JWT-protected sqld. |

## Accounts

| Variable | Default | Description |
| --- | --- | --- |
| `NUXT_OPEN_REGISTRATION` | `false` | `true` lets anyone register. Otherwise registration is invite-only after the first account. Build-time default: `OPEN_REGISTRATION`. |
| `NUXT_DEMO_ENABLED` | `false` | Offers a shared demo account on the sign-in page. Build-time default: `DEMO_MODE`. |
| `NUXT_DEMO_EMAIL` | `demo@event-calendar.app` | The demo account's email. |
| `NUXT_DEMO_PASSWORD` | `demo-calendar-1234` | The demo account's password. |

## Features

| Build time | Runtime override | Description |
| --- | --- | --- |
| `FEATURE_RECURRING_EVENTS` | `NUXT_PUBLIC_FEATURES_RECURRING_EVENTS` | Repeat options in the event dialog. The API rejects recurring events while this is off. |
| `FEATURE_COLLABORATION` | `NUXT_PUBLIC_FEATURES_COLLABORATION` | Real-time sync between a user's open tabs and devices over a WebSocket. |

Flags are off unless set to `true` or `1`.

## Analytics

| Variable | When | Description |
| --- | --- | --- |
| `NUXT_UMAMI_SITE_ID` | **build** | Umami site id (proxied through `/api/savory`). Setting it only at runtime has no effect. |
| `NUXT_RYBBIT_SITE_ID` | **build** | Rybbit site id. |
| `NUXT_PUBLIC_ENABLE_ANALYTICS` | runtime | `false` turns both off. |

## Server

| Variable | Default | Description |
| --- | --- | --- |
| `PORT` | `3000` | Port to listen on. |
| `HOST` | `0.0.0.0` in Docker | Interface to bind. |
