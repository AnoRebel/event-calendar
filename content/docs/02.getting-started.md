## Requirements

- [Bun](https://bun.sh) 1.3 or newer
- Node.js 22.5 or newer (the docs index uses Node's built-in SQLite)

## Steps

```bash
git clone https://github.com/AnoRebel/event-calendar
cd event-calendar
bun install
cp .env.example .env
```

The database defaults to a file at `.data/events.db`, so no database server is needed. Create its tables:

::install-tabs{run="db:migrate"}
::

Then start the dev server on [localhost:3000](http://localhost:3000):

::install-tabs{run="dev"}
::

The first account you create becomes the admin and needs no invite. To explore without signing up, enable the demo
account in `.env` and use **Explore the demo** on the sign-in page:

```ini [.env]
NUXT_DEMO_ENABLED=true
```

::callout{type="tip"}
Passkeys work on `http://localhost`. On any other host they need HTTPS — see [Self-hosting](/docs/self-hosting).
::

## Sample data

`bun run db:seed` adds a set of sample events to the database (owned by no user, so they are visible only to scripts
and the API). For realistic data in the UI, use the demo account, which is reseeded with events around today.

## Production build

```bash
bun run build
NUXT_APP_SECRET=$(openssl rand -base64 32) node .output/server/index.mjs
```
