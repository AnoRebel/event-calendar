The calendar ships as a [shadcn-vue](https://www.shadcn-vue.com) registry: the CLI copies the source into your project,
so it's yours to read and change. Nothing is installed as an opaque package.

## Requirements

- A Vue 3 (Vite) or Nuxt 4 project with Tailwind CSS v4.
- shadcn-vue initialised (`npx shadcn-vue@latest init`), so the `@/components/ui/*` and `@/lib/utils` imports resolve.

The UI primitives the calendar needs (button, dialog, select, popover and the rest) are declared as registry
dependencies, so the CLI adds any you don't have yet.

## Install

::install-tabs{item="event-calendar"}
::

The files land in `components/ui/event-calendar/`. Drag and drop needs a `DnDProvider` from
[`@vue-dnd-kit`](https://github.com/zizigy/vue-dnd-kit) around your app.

### Nuxt

::install-tabs{packages="@vue-dnd-kit/nuxt"}
::

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ["@vue-dnd-kit/nuxt"],
})
```

```vue [app.vue]
<template>
  <DnDProvider>
    <NuxtPage />
    <DragPreview />
  </DnDProvider>
</template>
```

### Vite + Vue

```vue [App.vue]
<script setup lang="ts">
import { ref } from "vue"
import { DnDProvider, DragPreview } from "@vue-dnd-kit/core"
import EventCalendar from "@/components/ui/event-calendar/EventCalendar.vue"
import type { CalendarEvent } from "@/components/ui/event-calendar/types"

const events = ref<CalendarEvent[]>([])
const add = (event: CalendarEvent) => events.value.push(event)
const update = (event: CalendarEvent) =>
  (events.value = events.value.map(e => (e.id === event.id ? event : e)))
const remove = (id: string) => (events.value = events.value.filter(e => e.id !== id))
</script>

<template>
  <DnDProvider>
    <EventCalendar :events="events" class="h-[80vh]" @event-add="add" @event-update="update" @event-delete="remove" />
    <DragPreview />
  </DnDProvider>
</template>
```

::callout{type="note"}
Give the calendar a height (for example `class="h-[80vh]"`). The week and day views then scroll internally, keep the
day headers in view, and scroll themselves while you drag near an edge.
::

## Optional layers

Each layer pulls in the ones before it.

| Item | Adds | Works in |
| --- | --- | --- |
| `event-calendar` | The calendar UI (views, dialog, drag, resize) | Vue 3, Nuxt |
| `event-calendar-data` | `useCalendarData()`: loads and saves events through `/api/events` | Vue 3, Nuxt |
| `event-calendar-persistence` | Nitro `/api/events` CRUD on libSQL + Drizzle, with schema and validation | Nuxt |
| `event-calendar-realtime` | A crossws WebSocket that syncs changes between open tabs and devices | Nuxt |

::install-tabs{item="event-calendar-persistence"}
::

The persistence layer is single-user out of the box and marks the places to add authorization with `TODO(auth)`.
After installing it, point `LIBSQL_URL` at a database (or keep the local file default) and create the table with
`drizzle-kit`. See [Self-hosting](/docs/self-hosting#database) for database options.

::callout{type="tip"}
The server layers import from `h3` so they run on any Nuxt 4 release. On Nuxt 4.6 or newer you can switch those imports
to `nuxt/server`, as this app does.
::
